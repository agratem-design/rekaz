## 1. ملخص الإنجاز والمعمارية المنفذة في المرحلة الرابعة

تم بنجاح استبدال نماذج الإدخال القديمة المنفصلة بأدراج سياقية تفاعلية وسريعة (`ProjectOperationDrawerShell`) تدعم إدخال وتعديل العمليات المالية للمشروع بدون مغادرة الصفحة، مع الامتثال التام والمحكم لقواعد المحاسبة المقفلة:

1. **الدرج السياقي الموحد للمشروع (`ProjectOperationDrawerShell.tsx`)**:
   - ينبثق من الجهة اليمنى (`dir="rtl"`) مع ترويسة سياقية تتضمن اسم المشروع ونوعه (مقاولات / تشطيبات).
   - يدعم التبديل السلس بين العمليات المصرح بها في المرحلة الرابعة (شراء مواد، خدمات ومقاولي باطن، مصروفات مباشرة).
   - محمي بواسطة `useUnsavedChangesGuard` لمنع فقدان البيانات عند الضغط بالخطأ على الخلفية أو مفتاح Escape أو التبديل.

2. **نموذج شراء المواد (`MaterialPurchaseForm.tsx`)**:
   - يدمج قائمة الموردين التفاعلية القابلة للبحث الفوري بالاسم والهاتف مع زر الإضافة السريعة.
   - يدعم الوضعين: إجمالي مباشر أو تفصيل بنود الفاتورة.
   - **فصل التكلفة المتكبدة عن السداد النقدي**: إمكانية قيد الفاتورة كذمة غير مسددة بالكامل، أو دفع جزء نقداً الآن.
   - **الدفعة النقدية الأولية**: يتم توثيقها حصرياً كحركة في جدول `purchase_payments` المرجعي، ولا يتم التلاعب اليدوي بحقل `purchases.paid_amount` التراكمي.
   - **معالجة الفشل الجزئي وإعادة المحاولة المتطابقة (`Idempotent Retry`)**: تمرير `idempotency_key` فريد على مستوى قاعدة البيانات لمنع تكرار قيد الدفعة النقدية في حال انقطاع الاتصال وإعادة المحاولة.
   - **حماية التعديل**: حظر تخفيض إجمالي الفاتورة عن إجمالي المسدد سابقاً، وحظر تغيير المورد في حال وجود دفعات تاريخية مسجلة على مستوى السيرفر بقواعد DB Trigger صارمة.

3. **نموذج الخدمات ومقاولي الباطن (`SupplierServiceForm.tsx`)**:
   - نموذج مخصص للخدمات الخارجية وأعمال مقاولي الباطن بقيمة متكبدة ووصف واضح دون حقول مواد مشوشة.
   - يدعم نفس المعمارية المحاسبية الموثوقة لقيد الاستحقاق والسداد النقدي عبر `purchase_payments` مع دعم الـ Idempotency.

4. **نموذج المصروفات المباشرة للمشروع (`DirectProjectExpenseForm.tsx`)**:
   - مصروف مباشر نقدي حتماً مرتبط بمشروع محدد (`project_id` إلزامي، وحظر تام للخلط مع المصروفات العمومية).
   - اختيار إلزامي للخزينة المتوافقة مع قطاع المشروع مع تصنيفات تفصيلية (نثريات، وقود، ضيافة، رسوم بلدية، إلخ).

5. **محدد الخزائن الذكي (`TreasurySelector.tsx`)**:
   - تصفية صارمة للخزائن بحسب قطاع المشروع (`contracting` مقابل `finishing`) مع استبعاد الخزائن غير المتوافقة.
   - عرض هرمي متناسق للخزائن الرئيسية وتفريعاتها مع الأرصدة الحالية الإرشادية.
   - فحص وتطبيق الخزينة الافتراضية للمشروع (`project.default_treasury_id`) مع حظر تام للاعتماد على `array[0]`.

6. **قائمة الكيانات والإنشاء المتداخل السريع (`EntityCombobox.tsx` + `QuickAddSupplierDialog.tsx`)**:
   - بحث فوري بالاسم والهاتف.
   - زر إضافة مورد جديد ينبثق في نافذة مستقلة تحافظ بنسبة 100% على مسودة الفاتورة في الخلفية.
   - عند الحفظ، يتم قيد المورد في قاعدة البيانات واختيار معرّفه الرقمي (`id`) فوراً في النموذج الأصل دون تخمين الاسم.
