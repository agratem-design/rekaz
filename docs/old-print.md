# قوالب الطباعة في النظام القديم (E:\ركاز)

> قراءة فقط. كل الطباعة القديمة تفتح نافذة جديدة (`window.open`) وتكتب فيها HTML ثم تستدعي `window.print()` تلقائياً.
> لا توجد مكتبات PDF في الطباعة نفسها (زر "تحميل PDF" في إيصال المشروع يحفظ عبر طباعة المتصفح).

## 1. الأساس المشترك — `src/lib/printStyles.ts`

### `openPrintWindow(title, content, settings)` — التقارير والكشوف
- A4، اتجاه RTL، خط **Tajawal** افتراضياً (أو Amiri/Cairo/Changa/Almarai أو خط مرفوع).
- **ترويسة** تتكرر في كل صفحة عبر `<thead>` لجدول تخطيط: يمين = الشعار + اسم الشركة (بلون العناوين) + الوصف المختصر؛ يسار = عنوان المستند + عنوان فرعي + بيانات (تُقرأ من عناصر `.print-report-title/subtitle/meta` في المحتوى). خط فاصل بلون العناوين. خيار قلب الاتجاه.
- **تذييل** ثابت يرسم خطاً فاصلاً فقط، ومساحة محجوزة في `<tfoot>`.
- خلفية صفحة اختيارية (صورة ورق رسمي) بموضع وحجم.
- شريط أدوات أعلى النافذة (اسم الشركة، العنوان، طباعة، إغلاق) يختفي عند الطباعة.
- **ألوان افتراضية (ذهبي):** رأس الجدول `#B4A078` بنص أبيض، العناوين `#7A5A10`، الحدود `#888`، صفوف `#f9f9f9/#fff`، مربع الإجماليات `#B4A078`.
- **قابلة للتخصيص من صفحة "تصميم الطباعة والهوية"** (`pages/PrintDesign.tsx`) بالمفاتيح:
  `print_table_header_color, print_table_border_color, print_section_title_color, print_table_row_even_color, print_table_row_odd_color, print_totals_bg_color, print_totals_text_color, print_table_text_color, print_header_text_color, print_table_font_size, print_header_font_size, print_title_font_size, print_border_width, print_border_radius, print_cell_padding, print_header_enabled, header_show_logo, header_show_name, header_show_tagline, header_logo_height, header_flipped, print_font_family, print_zoom_percent, report_background, report_padding_*_mm, report_footer_*`.

### `openReceiptPrintWindow(receipt, settings)` — السندات
- صندوق بعرض **148 مم** (قريب من A5) داخل صفحة A4، بإطار ذهبي وزوايا مستديرة.
- رأس: الشعار + اسم الشركة يميناً، ويساراً **نوع السند** + "رقم السند | التاريخ".
- صندوق المبلغ بارز (المبلغ بتنسيق `ar-LY` بالدينار).
- "صرفنا إلى السيد/ة" أو "استلمنا من السيد/ة" حسب النوع، "وذلك عن"، المشروع، الخزينة، طريقة الدفع، ملاحظات.
- توقيعان: "توقيع المستلم" و"توقيع الدافع / أمين الصندوق".
- **السند الملغى:** علامة مائية حمراء "سند ملغي" وشريط بسبب الإلغاء وتاريخه.
- الأنواع (14): سند صرف دفعة مورد، إشعار إيداع نقدي، سند صرف نقدي، سند صرف مستحقات فني، سند صرف مصروف، إشعار تحويل مالي، **سند قبض مالي**، سند صرف سلفة موظف، سند استرداد سلفة، سند صرف عهدة، سند تسوية عهدة، إيصال وديعة فني، سند رد وديعة فني، سند صرف إيجار معدات.
- لا يوجد **المبلغ كتابةً**، ولا ترقيم صفحات.

## 3. ما يُحسَّن في v2

- **مكوّن طباعة واحد** (`src/print/`) يُعرض داخل التطبيق في صفحة طباعة خاصة، بدل كتابة HTML في نافذة. `@media print` يخفي الشريط الجانبي والأزرار تماماً.
- الترويسة من `company_settings` فقط (الاسم، الوصف، الشعار، الهاتف، العنوان، المفوض بالتوقيع وصفته) — لا اسم ثابت.
- الألوان والخط من `print_settings` بنفس المفاتيح القديمة الأساسية (`print_table_header_color`، `print_section_title_color`، `print_totals_bg_color`، `print_font_family`…)، والافتراضي ألوان v2 (أخضر داكن + رملي).
- **المبلغ كتابةً بالعربية** (دينار ليبي ودرهم: 1 د.ل = 1000 درهم) في كل السندات.
- رقم المستند والتاريخ واضحان، مربع إجماليات، سطور توقيع، **ترقيم صفحات** للجداول الطويلة (عداد `@page`)، وتكرار رأس الجدول في كل صفحة.
- السند الملغى يُطبع بعلامة "ملغى" والسبب، كما في القديم.
- الترتيب: سند قبض ← فاتورة شراء ← سند صرف ← عقد ← كشف مشروع ← كشف عميل.
