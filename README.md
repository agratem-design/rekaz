# ركاز v2

منظومة إدارة شركة مقاولات وتشطيبات. المواصفات الكاملة في `docs/SPEC.md`.

## التشغيل

يتطلب Node.js 20 أو أحدث.

```bash
npm install
npm run dev
```

ثم افتح الرابط الظاهر (عادة http://localhost:5173).

ملف `.env` فيه عنوان قاعدة البيانات ومفتاحها العام (آمن للمتصفح؛ الصلاحيات تفرضها القاعدة).

## الهيكل

- `src/pages/` الشاشات، كل شاشة في ملف صغير.
- `src/components/` المكونات المشتركة (الجداول، النماذج الجانبية، التخطيط).
- `src/lib/` الاتصال بالقاعدة، والأنواع المولدة، والتسميات العربية.
- `supabase/migrations/` مخطط القاعدة بالترتيب، وهو المرجع الوحيد لها.
- `supabase/tests/` اختبارات المحاسبة (81 اختباراً) على Postgres محلي.
- `supabase/functions/admin-users/` دالة الخادم لإنشاء المستخدمين وتغيير كلمات المرور.

## قواعد لا تُكسر

- لا يُكتب أي سجل مالي مباشرة في جدول؛ كل عملية مالية عبر دوال القاعدة (`supabase.rpc`).
- لا يُحسب أي رصيد في المتصفح؛ الأرصدة من عروض القاعدة (`*_balances`, `project_financials`).
- الإلغاء بقيد عكسي، لا بالحذف.

## الدخول

المستخدمون الجدد يدخلون باسم المستخدم. حساب المدير المنقول من النسخة السابقة يدخل ببريده.
